## About text

Display Manager Pro is a macOS utility for display inspection and everyday display management. Review the information reported by macOS and display drivers, arrange connected screens, identify them with on-screen labels, and project mapping grids for setup and alignment.

## Release announcement

Display Manager Pro v1.1.0 is available for macOS.

This release adds configurable Mapping overlays, improves display identification, and brings display-role controls for individual screens and mirrored groups into the Arrangement view. It also includes Dark, Light, and System appearance options, a keyboard shortcut guide, and local diagnostic export.

Display features depend on macOS, the display driver, and connected hardware. Review the release notes and system requirements before installing, and inspect diagnostic reports before sharing them.
