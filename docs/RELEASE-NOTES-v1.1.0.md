# Display Manager Pro v1.1.0

Display Manager Pro v1.1.0 brings display inspection, arrangement, and visual mapping tools together in a refreshed macOS app.

## Highlights

- **Display arrangement:** Drag displays to change their layout, set the main display, and configure roles for individual displays and mirrored groups.
- **Identify:** Show a high-contrast label on connected displays to identify which screen is which.
- **Mapping:** Project configurable mapping grids on an individual display or across all displays.
- **Display controls:** Inspect and change supported resolution, refresh-rate, color-mode, ICC-profile, and orientation settings.
- **Display information:** Review current output, available modes, hardware and EDID data, profiles, and connection details.
- **Appearance and shortcuts:** Choose Dark, Light, or System appearance and use the in-app keyboard shortcut guide.
- **Diagnostic export:** Save a local report containing display and connection data for troubleshooting.

## Compatibility and limitations

- macOS only. Consult the release download details for the tested macOS versions and processor architectures.
- Available settings depend on macOS, the display driver, and connected hardware.
- Diagnostic exports may include device identifiers and hardware details. Review files before sharing.

## Installation

Open the downloaded disk image and drag **Display Manager Pro.app** to **Applications**. The release page should identify whether that build is signed, notarized, and which systems it has been tested on.
